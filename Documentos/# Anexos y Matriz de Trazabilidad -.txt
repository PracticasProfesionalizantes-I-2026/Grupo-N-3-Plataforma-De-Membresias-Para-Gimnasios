# Anexos y Matriz de Trazabilidad - Sistema Gym Membership

## 1. Anexo: Códigos HTTP Utilizados
* **201 Created**: Utilizado cuando un recurso (como un nuevo socio, plan de membresía, horario o actividad) se crea exitosamente en el sistema.
* **200 OK**: Utilizado para confirmar operaciones de actualización o consulta exitosas.
* **400 Bad Request**: Utilizado cuando una validación falla (ej. campos obligatorios faltantes, formato incorrecto de email, edades fuera de rango o precios/cupos inválidos).
* **401 Unauthorized**: Utilizado cuando la solicitud carece de credenciales de autenticación válidas (token JWT ausente o inválido).
* **403 Forbidden**: Utilizado cuando el usuario autenticado no posee los roles o permisos requeridos para la operación.
* **404 Not Found**: Utilizado cuando un recurso solicitado no existe en el sistema.
* **409 Conflict**: Utilizado cuando existe un conflicto en la lógica de negocio (ej. socio duplicado por DNI/email, nombre de plan o actividad en uso, solapamiento de horarios o dependencia por relaciones existentes).
* **500 Internal Server Error**: Utilizado ante errores inesperados no controlados en el servidor.
